📊 Google Sheets Sync

Every note you save will automatically appear as a new row in your Google Sheet. Follow the steps below once to set it up.

How to set it up (one time)
1
Go to sheets.google.com and create a new blank spreadsheet
2
Click Extensions → Apps Script in the top menu
3
Delete all existing code and paste this code:
function doGet(e) { var sheet = SpreadsheetApp .getActiveSpreadsheet() .getSheets()[0]; if (sheet.getLastRow() === 0) { sheet.appendRow([ 'ID','Category','Title', 'Details','Deadline','Saved At' ]); } var p = e.parameter; var cats = { task:'Task', instruct:'Instruction', decision:'Decision', deadline:'Deadline' }; sheet.appendRow([ p.id, cats[p.cat]||p.cat, p.title, p.body||'', p.deadline||'', new Date(Number(p.ca)).toLocaleString() ]); return ContentService .createTextOutput('ok'); }
4
Click the 💾 Save icon (or Ctrl+S)
5
Click Deploy → New Deployment
6
Set type to Web app, Execute as: Me, Who has access: Anyone → Click Deploy
7
Copy the URL it gives you and paste it in the field above → tap Connect
